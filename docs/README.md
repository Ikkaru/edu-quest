# 📂 Installation
## via file download
1. Download the folder
2. Unzip the Folder
2. Run EduQuest.exe

# ⚙️Development
## via github (for development)
1. git clone https://github.com/Ikkaru/edu-quest.git
2. open the folder using VSCode.
3. Press F5 to run game in debug mode.
